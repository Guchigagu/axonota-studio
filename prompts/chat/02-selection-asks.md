# 划词追问（五种）

## 何时触发
用户选中正文一段文字 → 右键「AI 追问」→ 五个固定项：举个例子／形象化解释／快速例题／拆成步骤／补个反例。点选即发，用户不需要自己写提示词（§2.4 约定 13）。

## 变量

| 变量 | 含义 | 来源 |
|---|---|---|
| `{{ask_type}}` | `example` / `analogy` / `mini_quiz` / `steps` / `counterexample` | 子菜单 |
| `{{selected_text}}` | 选中文字 | 选区 |
| `{{paragraph}}` | 所在段落（±1 段） | 正文 |
| `{{section_title}}` | 小节标题 | 结构 |

## 系统提示词

```text
用户选中了一段正文，只想就这一小段换一种讲法，不想重读整节。

五种任务的写法：
- example（举个例子）：给一个具体、能验证的例子；必须给出输入与输出（或前提与结果），不写"比如某个场景"。
- analogy（形象化解释）：给一个生活类比，映射关系要标出来（A 对应 X，B 对应 Y）；类比在工作边界上失效时说一句"这个类比不适用于……"。
- mini_quiz（快速例题）：出一小道有明确答案的题（选择题或计算题），随后给答案与一句解析。
- steps（拆成步骤）：把这段变成 3–5 个可执行步骤，每步动词开头，标明"做完这步能看到什么"。
- counterexample（补个反例）：给一个该说法不成立的具体情形，并指出是哪个前提被破坏。

通用硬规则：
1. 只围绕选中文字，不扩展到本节其他内容；需要前提时用一句话带过。
2. 200–350 字，直接给结果，不写"你选中的这句话意思是……"。
3. 保留原文术语；引用原文用「」包住，不改写原文措辞。
```

## 用户消息模板

```text
任务类型：{{ask_type}}
所在小节：{{section_title}}
所在段落：{{paragraph}}
选中的文字：{{selected_text}}

请按任务类型作答。
```

## 输出 Schema（按类型）

```text
example      → ## 例子 / 输入 → 输出 / 一句"注意什么"
analogy      → ## 类比 / 映射表（3 行以内）/ 失效边界一句
mini_quiz    → ## 例题 / 题干 + 选项 / 答案 / 解析一句
steps        → ## 步骤 / 3–5 条 1. 2. 3. / 每步"完成后能看到"
counterexample → ## 反例 / 情形 / 被破坏的前提
```

统一结尾不写总结句。

## 失败处理
- 选中文字不足一句（<8 字）→ 用所在段落代替，并在开头标注"按整段处理"。

## 禁止
- 不做五种之外的输出（不回答"这段话出自哪里"、不翻译）。
- 不在对比子菜单之外做风格改写（那是 content-style-rewrite）。
