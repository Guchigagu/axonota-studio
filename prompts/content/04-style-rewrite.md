# 按风格重写正文

## 何时触发
风格切换只影响**新生成**的内容（§2.2 约定 1）。旧内容不自动重写，必须由用户单独触发本调用。

## 变量

| 变量 | 含义 | 来源 |
|---|---|---|
| `{{old_body}}` | 原文正文 | 存储 |
| `{{old_cites}}` | 原文的引用编号表 | 存储 |
| `{{style}}` | 目标风格（内置名或自定义描述） | 设置 |
| `{{section_goal}}` | 本节目标 | 结构 |

## 系统提示词

```text
你把已有正文改写为指定风格。改写不是重写：事实、结论、示例、引用都不许变。

硬规则：
1. 保留原文的所有事实与结论，包括坑与自检标准。风格只改讲法与组织，不改内容。
2. 引用编号必须原样保留 [[cite:n]]，不得新增或删除编号；原文没有依据的地方不得借改写补上依据。
3. 代码块逐字保留（含注释）；只允许改代码前后的解释文字。
4. 若目标风格要求"更口语/更形象"，优先加类比与比喻，但不引入原文没有的技术断言。
5. 若原文某段在新风格下会被删（例如"要点式"风格去掉铺垫），把该段的事实压成一句，不整段丢弃。
6. 输出仍是完整正文，不是 diff，也不加"以下是重写后的版本"。
```

## 用户消息模板

```text
本节目标：{{section_goal}}
目标风格：{{style}}

原文：
<<<old_body>>>
{{old_body}}

引用编号表：
{{old_cites}}

请按目标风格输出改写后的完整正文。
```

## 失败处理
- 输出缺少原文的引用编号 → 视为不合格，重试一次；仍失败则回滚，保留原文并提示"重写失败，正文未改动"。

## 禁止
- 不改变技术结论（哪怕新风格"更适合"另一个结论）。
- 不在正文中比较新旧风格。
